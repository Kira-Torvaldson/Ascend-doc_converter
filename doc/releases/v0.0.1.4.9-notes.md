## Ascend 0.0.1.4.9

Stabilisation patch — unified CI validation before `0.0.2.0 beta` (ASC-015 → ASC-016).

### Added

- `npm run check:ascend:ci` — one command for full Ascend validation (matches GitHub Actions job `ascend`).

### Changed

- CI job `ascend` runs `check:ascend:ci` after installing root, backend, and frontend dependencies (+ Pandoc).
- Root `npm ci` added to `ascend` job so `test:abuse` (Mocha) runs reliably in CI.

### Validation

```bash
npm run check:ascend
npm run check:ascend:ci
```
