## Ascend 0.0.1.4.7

Release qualité conversion et industrialisation CI (ASC-001 → ASC-010).

### Added

- Scripts `release:bump` et `check:version` (7 zones de version Ascend).
- Job CI **ascend** : golden corpus, roundtrip sémantique, e2e AsciiDoc/Markdown, tests d'abus API.
- Corpus golden (15 scénarios) et tests roundtrip adoc ↔ md.
- Enveloppe d'erreur structurée (`error.code`, `category`, `hint`) + messages UI.
- Corrélation `X-Request-Id` / `meta.requestId`.
- Endpoints `GET /api/metrics` et `GET /api/config/limits`.
- Tests d'abus (`npm run test:abuse`).
- Pandoc dans l'image Docker `container/backend`.
- Runbook opérations : `doc/guides/operations/runbook.md`.

### Changed

- Limite d'entrée unifiée à **5 Mo** (EnvMap, Express, modules, UI, Nginx 6m).
- Documentation limites dans `doc/references/configuration.md`.

### Validation

```bash
npm run check:version
npm --prefix api/backend run test:golden
npm --prefix api/backend run test:roundtrip
npm run test:abuse
npm --prefix api/frontend run test
```
