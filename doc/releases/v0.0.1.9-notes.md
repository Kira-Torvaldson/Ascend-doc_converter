## Ascend 0.0.1.9

Patch ConversionResult de bout en bout (orchestrateurs + Pandoc) + wrappers HTML, sur la base 0.0.1.8.5.

### Highlights

- **Pandoc** : chemin commande → `ConversionResult` natif (`FORMAT_UNSUPPORTED`, `CONVERSION_TIMEOUT`, `OUTPUT_NOT_CREATED`, …)
- **Orchestrateurs** : erreurs structurées précoces ; helper `orchestrator-result.js` ; plus de stringify lossy
- **Proxy** : `classifyProxyFailure` lit `error.code` ; `body.error` reste une string (bulk)
- **HTML** : modules `html-markdown` / `html-plain` + route `/api/from-html`
- **DX** : résolution binaire Pandoc Windows/PATH ; scripts `test:pandoc-result`, `test:proxy-failure-classify`, `test:html-wrappers`
