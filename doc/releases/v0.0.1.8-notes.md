## Ascend 0.0.1.8

Patch contrat — adoption `ConversionResult` sur les routes sécurisées + EnvMap complété.

### Added

- `POST /api/convert` : contrat `ConversionResult` standardisé (succès = champs legacy + `conversionResult` ; échec = forme ConversionResult + `detail`).
- `POST /api/proxy/convert` : `conversionResult` ajouté à côté de la forme legacy `{ success, result | error }` (compatibilité bulk-processor conservée).
- Scripts contrat `verify-e2e-convert-contract.js` / `verify-e2e-proxy-convert-contract.js` intégrés à `check:ascend:ci`.
- Enveloppe erreur : codes `CONFIRMATION_*` → catégorie `VALIDATION_ERROR` + hints français.
- EnvMap : clés `API_KEY` (sensible), `FRONTEND_URL`, `ASCEND_REPORTS_DIR`.
- Scénario Pandoc (markdown → html) dans `verify-e2e-convert-contract.js` : exécuté quand le binaire Pandoc est présent (CI/Docker), ignoré proprement sinon.
- `POST /api/roundtrip` : `conversionResult` ajouté à côté de la forme legacy `{ success, state, logs, errors }` (dernière route de conversion hors contrat).
- Script contrat `verify-e2e-roundtrip-contract.js` intégré à `check:ascend:ci` (scénario succès conditionné à Pandoc).

### Performance

- Serveur Pandoc persistant (`pandoc server`, Pandoc >= 3.0) : les conversions texte évitent le démarrage du binaire à chaque requête (~50 ms gagnées par requête en local, davantage sous charge) ; démarrage paresseux, repli CLI automatique si indisponible, désactivable via `PANDOC_SERVER_ENABLED=false` (nouvelle clé EnvMap). Fins de ligne normalisées en LF sur les deux chemins.
- `/api/to-markdown` : conversion entièrement en mémoire (`convertAsciiDoc` direct : downdoc avec fallback Pandoc) — plus aucun fichier temporaire ni accès disque sur le chemin chaud.
- Helpers Pandoc (`/api/to-asciidoc`, `/api/from-html` formats texte) : entrée via stdin, sortie via stdout (`safeSpawn` supporte `stdinData`) — zéro fichier temporaire ; les formats binaires (pdf/docx/epub) gardent le chemin fichier.
- Routes et convertisseurs ne bloquent plus l'event loop sur les gros documents : les I/O de fichiers temporaires restantes du chemin de requête sont asynchrones (`fs/promises`).
- `MimeTypeDetector` : échantillon de 4 Ko au lieu du fichier entier ; heuristique texte sans allocation par caractère.
- `basicCleanup` (post-traitement downdoc) : une seule passe au lieu de ~7 (corpus golden vérifié identique).
- Pipeline roundtrip : réutilisation des contenus déjà lus (plus de double lecture au succès).
- Compression HTTP des réponses (`compression`, seuil 1 Ko) : les documents convertis de plusieurs Mo transitent compressés.
- Helpers Pandoc : timeout depuis EnvMap (`CONVERSION_TIMEOUT_MS`) au lieu de 30 s codés en dur.
- Script `bench-large-doc.js` pour mesurer la latence (4 Mo ≈ 0,5 s sur `/api/to-markdown`).

### Changed

- `api-key.middleware`, `cors.middleware`, `/api/metrics` : lecture de configuration via EnvMap (plus de `process.env` direct).
- Échecs de validation Zod (`validate.middleware`) : enveloppe erreur standardisée (`error.code = INVALID_INPUT`, catégorie, hint, issues dans `error.details`) au lieu de `{ error: 'Invalid request', issues }`.
- EnvMap devient la source unique de configuration : `server.js`, `error-handler.middleware`, `structured-logger` et `pipeline-security` ne lisent plus `process.env` directement (fallbacks legacy supprimés).
- Limites de `secure-converter.js` alignées sur EnvMap : `MAX_FILE_SIZE` suit `MAX_INPUT_SIZE_MB` et `DEFAULT_TIMEOUT` suit `CONVERSION_TIMEOUT_MS` (auparavant 50 Mo / 30 s codés en dur).

### Fixed

- `/api/convert` échouait à l'exécution pour toute conversion : appel instance d'une méthode `static` (`detectUnauthorizedAccess`) + chemin `require` du lazyload erroné dans `secure-converter.js`.
- `ConfirmationTokenError` : champs `code` / `message` inversés (ordre des arguments du constructeur).
- Timer de nettoyage des tokens : `unref()` pour ne plus bloquer la sortie des scripts et des tests.
- `SecurityLogger` ne créait jamais son dossier de logs (création dans un constructeur jamais invoqué par les méthodes statiques) : les logs sécurité/anomalies échouaient en `ENOENT`.

### Removed

- `api/backend/config/index.js` — module de configuration mort (aucune référence restante).
- `api/backend/server-legacy.js` — point d'entrée legacy (aucune référence restante).
