## Ascend 0.0.1.9.1

Patch fiabilité MD ↔ HTML/TXT (UI + API), sur la base 0.0.1.9.

### Highlights

- **Routes** : `POST /api/from-markdown`, `POST /api/from-text` ; clés `/api/from-html` normalisées
- **UI** : buffer `otherOutput` (source Markdown intacte) ; session / historique / ZIP / diff alignés
- **Aperçu** : HTML en iframe sandbox ; toggle Texte/Aperçu selon le format
- **Fiabilité** : rejet `EMPTY_OUTPUT` ; timeout Pandoc non masqué ; abort + timeout client aligné backend
- **Import** : `.html` / `.htm` acceptés en source
- **CI** : scénarios représentatifs `/api/from-markdown` dans `check:ascend:ci`
