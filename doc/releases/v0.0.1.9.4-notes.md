## Ascend 0.0.1.9.4

Patch UX / productivité sur la base 0.0.1.9.3 : onglets de session, palette de commandes, conversion dossier, et peaufinage des flux existants.

### Highlights

- **Sessions** : onglets (renommer / dupliquer / réordonner), indicateur dirty, confirmation avant fermeture
- **Palette Ctrl+K** : commandes filtrables + raisons quand désactivées
- **Dossier** : file de conversion multi-fichiers, progression, ZIP des résultats, détails erreur/skip
- **Workspace** : présets (équilibré / focus source-résultat / stacked / zen), splitter, mode zen résultat, aperçu détaché
- **Édition** : find (Aa / mot / regex), goto ligne, warnings cliquables → ligne, comparaison historique A/B
- **Header** : chips profils / pins retirés (doublons) ; profils restent en sidebar
