## Ascend 0.0.1.9.2

- **Métriques** : `errors_by_code` + `failures_by_route` ; persistance ring buffer `reports/conversion-metrics.json` ; panneau Paramètres → Métriques (auto-refresh) + badge header si échecs
- **Fail-contracts** : `/api/from-markdown`, `/api/from-text`, `/api/from-html` (`EMPTY_INPUT`, `FORMAT_UNSUPPORTED`, `EMPTY_OUTPUT`, …)
- **Pandoc DX** : shutdown Windows `taskkill /T /F` ; helper `exitClean` pour les scripts verify/bench
- **UX** : bannière `ENGINE_FALLBACK` ; hints timeout renforcés
