## Ascend 0.0.1.9.5

Patch fiabilité + découpage UI sur la base 0.0.1.9.4 : sessions de conversion plus sûres, et `App.tsx` allégé via des hooks dédiés.

### Highlights

- **Sessions** : résultat livré sur l’onglet d’origine, skip si conflit, historique depuis le snapshot, plus de buffers fantômes à la restauration
- **Garde-fous** : dirty sans résultat, token vs confirmation, favoris/récents verrouillés pendant convert, session corrompue / quota visibles
- **Sécurité** : aperçu HTML assaini
- **Découpage** : `useSourceImport`, `useConversionFlow`, `useAutoConvert`, `useFolderBatchStart`, `useDocumentExport`, `useUserSettingsPanel`, `useAppCommands`
