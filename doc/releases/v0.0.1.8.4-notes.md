## Ascend 0.0.1.8.4

Patch précision conversion + capacité soft-auto + stabilisation éditeur, sur la base 0.0.1.8.3.

### Highlights

- **Précision ADOC↔MD** : notes multi-paragraphes, gras dans les admonitions, listes de définitions, xrefs/ancres (`{#id}`), listes imbriquées locales, bascule Pandoc pour tables à spans
- **Capacité soft-auto** : profil machine (RAM/CPU) pour plafonds entrée / concurrence / timeout, exposé via `/api/config/limits`
- **Notes AsciiDoc** : normalisation blockquotes (`> **NOTE:**`) en mode default et BookStack ; plus de HTML `<dl>` brut
- **Corpus** : goldens admonition/xref mis à jour ; fixtures `06-definition-list`, `07-admonition-multipara` ; scripts `test:precision` / `test:admonitions` / `test:capacity` en CI
- **Éditeur** : fluidité find/diff/profils/gouttière ; découpe `ConversionSidebar` / `AppConfirmModals`
