## Ascend 0.0.1.5

Docker industrialisation patch — backend image build gate before `0.0.2.0` beta (ASC-017 → ASC-018).

### Added

- `npm run check:docker:backend` — builds `container/backend/Dockerfile` from repo root and verifies Pandoc in the image.
- CI job `docker` — runs on every push/PR alongside `ascend`.

### Changed

- Version alignment across frontend/backend packages, lockfiles, README badge, and app metadata.
- Runbook and roadmap updated for release `0.0.1.5`.

### Validation

```bash
npm run check:ascend:ci
npm run check:docker:backend
```
