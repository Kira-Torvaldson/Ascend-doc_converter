## Ascend 0.0.1.9.3

Patch UI / i18n sur la base 0.0.1.9.2 : la **langue du compte** traduit l’interface Ascend (FR, EN, ES, DE), indépendamment de la langue de conversion.

### Highlights

- **i18n** : catalogues `messages` / `appMessages` / `extraUiMessages` ; `LocaleProvider` + `useT()` ; `html[lang]` synchronisé
- **Compte** : langue UI vs langue conversion ; presets Perso/Pro/Client ; signature ; fill métadonnées
- **Interface** : accents (dont métaux), densités panneaux, sidebar, fond, confort
- **Chrome** : Source/Résultat, Convertir, sidebar options, modales, historique, snackbars/status localisés
