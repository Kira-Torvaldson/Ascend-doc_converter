## Ascend 0.0.1.5

Patch d'industrialisation Docker — contrôle de build de l'image backend avant `0.0.2.0` beta (ASC-017 → ASC-018).

### Ajouté

- `npm run check:docker:backend` — build `container/backend/Dockerfile` depuis la racine du dépôt et vérification de Pandoc dans l'image.
- Job CI `docker` — s'exécute à chaque push/PR aux côtés de `ascend`.

### Modifié

- Alignement des versions entre packages frontend/backend, lockfiles, badge README et métadonnées de l'application.
- Runbook et roadmap mis à jour pour la release `0.0.1.5`.

### Validation

```bash
npm run check:ascend:ci
npm run check:docker:backend
```
