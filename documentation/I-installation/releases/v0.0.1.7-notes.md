## Ascend 0.0.1.7

Patch UX + CI Docker frontend.

### Added

- `check:docker:frontend` / `check:docker` — build image frontend + vérif. nginx/SPA.
- CI : étape build frontend dans le job `docker`.
- Modale erreur : `error.code`, hint, `requestId`.
- Footer : limite source (Mo) + repère runbook.

### Changed

- Visibilité photo Rafale (voiles allégés).
- Historique (`HistoryModalV2`) aligné variables thème modal.
- Toute erreur structurée avec `error.code` ouvre la modale.

### Validation

```bash
npm run check:version
npm run check:ascend:ci
npm run check:docker
```
