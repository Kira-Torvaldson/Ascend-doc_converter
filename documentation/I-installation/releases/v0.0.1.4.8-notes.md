## Ascend 0.0.1.4.8

Patch complétant les écarts DoD de 0.0.1.4.7 : alignement du corpus golden sur la spec, CI e2e étendue et couverture UI complète des erreurs de sécurité (ASC-011 → ASC-014).

### Ajouté

- Fixtures : `adoc/complex/05-xref.adoc`, `adoc/simple/06-utf8.adoc`, `markdown/complex/01-table.md` (16 scénarios golden).
- CI e2e : `/api/text-to-markdown` et `/api/from-html` (contrats représentatifs + échec).
- Messages et hints UI en français pour tous les `SECURITY_ERROR_CODES`.
- `npm run check:ascend` — chaîne de validation locale pour l'application Ascend.
- Notes de release pour 0.0.1.4.7 (`doc/releases/v0.0.1.4.7-notes.md`).

### Modifié

- Les tests roundtrip sémantiques utilisent la fixture de référence croisée (`05-xref`) au lieu de l'UTF-8 dans l'ensemble complex.
- `doc/specs/axes-ameliorations-0.0.1.4.7.md` §1 documente les limites effectives post ASC-008.

```bash
npm run check:ascend
node api/backend/scripts/verify-e2e-text-to-markdown-representative-scenarios.js
node api/backend/scripts/verify-e2e-from-html-representative-scenarios.js
```
