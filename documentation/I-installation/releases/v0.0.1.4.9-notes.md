## Ascend 0.0.1.4.9

Patch de stabilisation — validation CI unifiée avant `0.0.2.0 beta` (ASC-015 → ASC-016).

### Ajouté

- `npm run check:ascend:ci` — une commande pour la validation Ascend complète (identique au job GitHub Actions `ascend`).

### Modifié

- Le job CI `ascend` exécute `check:ascend:ci` après installation des dépendances racine, backend et frontend (+ Pandoc).
- `npm ci` racine ajouté au job `ascend` pour que `test:abuse` (Mocha) s'exécute de manière fiable en CI.

### Validation

```bash
npm run check:ascend
npm run check:ascend:ci
```
